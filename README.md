🔗 Smart URL Shortener

A modern and responsive URL Shortener web application built using React, Vite, and Firebase.
This project allows users to generate short links, create QR codes, manage URLs, and access links seamlessly across devices after deployment.

🚀 Features
🔐 User Authentication (Firebase Auth)
✂️ URL Shortening System
📱 QR Code Generation
🌐 Fully Responsive UI
⚡ Fast Build & Deployment with Vite
☁️ Firebase Integration
📊 Clean Dashboard Interface
🔗 Shareable Short Links
🖼️ Realistic QR Support for Production URLs
🚀 GitHub Pages / Vercel Deployment Ready
🛠️ Tech Stack
Frontend: React.js + Vite
Backend / Database: Firebase
Authentication: Firebase Auth
Styling: CSS / Tailwind (if used)
QR Generator: QRCode Library
Deployment: GitHub Pages / Vercel
